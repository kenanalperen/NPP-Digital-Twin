## How to Open the Simulation

1. **Download the Unity package**  
   Download the file `prototype_v1.unitypackage`.

2. **Create or open a Unity 3D project**  
   Ensure it is a **3D Universal Render Pipeline (URP) project**.

3. **Import the Unity package**  
   Import the `prototype_v1.unitypackage` file into your Unity project workspace.

4. **Explore the simulation**  
   Once imported, you can navigate and interact with the Zwentendorf NPP digital twin within Unity.
